## 💎 Overview

**Pranay CP Intelligence Suite** is a purpose-built sales operations workspace engineered for luxury real estate developers and channel sales teams in high-value corridors (Golf Course Road, Golf Course Extension, Dwarka Expressway, and Delhi NCR).

The platform shifts sales teams away from superficial vanity metrics (unanswered calls, unverified logs) toward **high-velocity commercial milestones**:
* **Channel Partner Relationship Health Score (0–100)**: Algorithmic ranking based on recency, active buyer mandates, and commitment adherence.
* **Executive Command Centre**: Answers *"Where will luxury revenue close in the next 7 to 30 days?"*
* **Deal Pipeline & Kanban**: Live stage progression from client lead to private site walkthrough, price negotiation, and closed booking with values in ₹ Crores.
* **Unified Action Queue**: Overdue, today's, and upcoming commitments with 1-click completion and automated rescheduling.
* **Outcome Targets Matrix**: Measures meaningful conversations, meetings, leads, site visits, and bookings across team members (Jasjeet, Prateek, Naman, Pranay).
* **Excel Studio**: Downloadable templates, file preview with duplicate CP detection, row-level validation, and instant rollback snapshots.
* **AI Sales Director**: Powered by Google Gemini 2.5 Flash for pre-meeting broker dossiers and deal negotiation strategy.

## 🚀 Quick Start

### Prerequisites
* Node.js 20+
* npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/PranayPeriwal13/<your-repo-name>.git

# Navigate to project
cd <your-repo-name>

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:3000` in your browser.

## 📦 Production Build & GitHub Pages Deployment

To build self-contained static assets for GitHub Pages:

```bash
npm run build
```

This compiles optimized assets with relative paths (`./assets/`) into the `dist/` folder, ready for deployment to GitHub Pages or any static host.
